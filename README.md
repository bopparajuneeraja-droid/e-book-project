# E-Book Website

## About the Project
The E-Book Website is a user-friendly website designed to help users explore e-books online.

## Features
- Clean and simple user interface
- Easy navigation
- Attractive design
- E-book related content

## Technologies Used
- HTML5
- CSS3

## Project Files
- index.html – Main webpage
- style.css – Website styling
- home1.webp – Image asset
- image2.png – Image asset

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
